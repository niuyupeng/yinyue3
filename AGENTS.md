# AGENTS.md

Guidance for future Codex work in this repository:

- Never fabricate results, tables, ablations, timings, or qualitative claims.
- Always run tests after code changes when the environment permits it.
- Keep model and batch-size defaults small enough for an RTX 4060 Ti with 16GB VRAM.
- Use MusicXML and score-level SATB terminology. Do not reframe this as pop MIDI production.
- MIDI numbers may appear as internal symbolic pitch tokens only.
- Document all commands run and summarize their outcome.
- Treat the smoke experiment as a software check, not a publishable result.
- If Roman numeral labels or chord labels are unavailable, mark harmony-rule limitations explicitly.
