# Remaining release blockers

This curated tree is structurally ready for review, but it is not yet a final archival release.

- Real author names, affiliations, ORCID, corresponding-author details, and contribution statements must replace the metadata templates.
- A code/data license must be chosen and added after author approval.
- The final public release tag or immutable commit must be recorded in the manuscript and reproducibility manifest.
- Redistribution terms must be checked for every processed data artifact and any included third-party material.
- A permanent archival DOI is optional at repository stage but should be added before final publication if required by the journal.
- Expert-rating claims remain pending until real anonymized rating returns exist.
- External BCFB/CPDL materials remain pilots unless a curated, license-checked benchmark is completed.

No result, author identity, license, DOI, expert rating, or external-benchmark claim should be invented to make this checklist appear complete.
