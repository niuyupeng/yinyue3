# Data and code availability

## Code

The source code, configurations, tests, manuscript sources, and figure/table source data are maintained in the project repository. The final manuscript must cite an accessible public repository URL and an immutable release tag or commit.

## Processed data

The main processed dataset is derived from the Bach chorales distributed through `music21`. The repository may include compact processed tensors and split metadata when redistribution is compatible with upstream terms. The raw upstream corpus is not republished by this project.

The BCFB and CPDL materials are external-source pilots. They remain subject to original distribution, attribution, and licensing conditions and must not be described as a fully curated external benchmark without additional review.

## Release requirements before publication

- make the GitHub repository publicly readable;
- create an immutable release tag or archive;
- verify that included data and media have redistribution permission;
- add the final repository URL and release identifier to the manuscript;
- add an archival DOI if required by the target journal;
- replace provisional author, license, and release metadata;
- record the exact release commit in the reproducibility manifest.

No public DOI or completed expert-rating dataset is implied by this candidate tree.
