# SCI repository release checklist

- [ ] Confirm author names, order, affiliations, ORCID, and corresponding author.
- [ ] Choose and add a code/data license.
- [ ] Replace all `TBD` fields in `CITATION.cff.template` and rename it to `CITATION.cff`.
- [ ] Make `https://github.com/niuyupeng/yinyue3` publicly readable.
- [ ] Create an immutable release tag or archival snapshot.
- [ ] Verify that the release contains no passwords, tokens, private identifiers, `.venv`, caches, or unreviewed raw corpora.
- [ ] Verify third-party attribution and redistribution terms for every included dataset and media file.
- [ ] Re-run tests from a clean environment.
- [ ] Rebuild the manuscript and inspect the PDF.
- [ ] Update Data Availability and Code Availability with the exact public URL and release identifier.
- [ ] Regenerate the reproducibility manifest and claim-evidence ledger.
- [ ] Confirm that expert evaluation and external benchmark claims remain marked pending when evidence is absent.
