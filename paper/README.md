# Manuscript sources

The canonical submitted English manuscript is `main_submission.tex` with its compiled `main_submission.pdf`. It is a self-contained LaTeX entry point. The accompanying figure directory contains the rendered figures, captions, and figure source-data CSV files.

Build intermediates such as `.aux`, `.log`, `.bbl`, `.blg`, and `.out` are intentionally excluded from the repository. The checked-in PDF is the manuscript artifact corresponding to the checked-in source.
