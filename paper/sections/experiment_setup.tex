\section{Experiment Setup}

\subsection{Dataset}

The default corpus is the Bach chorale collection distributed with music21. The processed full dataset in the inspected workspace contains 371 chorales represented as tensors of shape \(371 \times 256 \times 4\). The deterministic split contains 297 training chorales, 37 validation chorales, and 37 test chorales. Automatic harmonic-label fields are stored with the processed dataset, including key labels, chord roots, chord qualities, Roman numerals, seventh-chord flags, dominant-function flags, and phrase-end flags.

\subsection{Full Local Protocol}

The primary full experiment suite contains an LSTM baseline, a vanilla/no-constraints Transformer, a proposed rule-guided Transformer, a masked infilling task, and a soprano-to-SATB task. The full-training configuration uses maximum sequence length 256, hidden size 384, six Transformer layers, six attention heads, batch size 8, mixed precision on CUDA, gradient clipping, deterministic seeds, \texttt{num\_workers=0} on Windows, and early-stopping patience 10.

\subsection{Smoke Validation}

The CPU smoke experiment uses at most 20 chorales, one training epoch, and short evaluation/generation passes. It validates parsing, tokenization, training, evaluation, MusicXML export, and report generation. Smoke numbers are not treated as final scientific results.
